# 历史与视频共同影响模拟伤病概率：数据补齐方案

日期：2026-10-24（America/Toronto）。用户目标：视频也必须参与概率计算。状态：下文保留研究提案；实际最小演示已实现，尚未训练或验证联合预测模型。

实施更新：用户进一步要求以 demo 展示为目标、最小范围合成并控制成本。已交付 [6 案例最小演示](../data/demo/README.md)：复用四段当前视频和一段参考，生成两组历史及六个离线未来抽样，测量真实视频像素，并在独立分析师页展示规定随机事件过程的条件概率。10 月 26 日新增 S006/S004 像素步态特征与固定历史对照，当前优先人工验收。没有执行下文 200–500 球员赛季/40 视频/批量 VLM/模型训练计划；这些扩量建议暂缓。下文保留为后续研究路线，不代表当前实现。

## 1. 目标与当前缺口

目标是估计 `P(未来 7 天新发非接触 time-loss injury | 截止时可知的历史, 截止时的视频观察)`。视频通过实际提取的动作特征进入预测器，概率由可复现的联合模型计算；不由 LLM 主观增减百分点。

这是合成世界内的预测研究。动作与未来事件的统计关系将由模拟假设建立；在同类模拟数据上通过测试只能说明模型在这些假设下工作，不能证明动作对真实伤病具有预测力。原生成器中 ACWR、疲劳等乘数也不视作已经验证的医学规律。

| 数据层 | 当前证据 | 本目标缺少的数据 |
|---|---|---|
| 历史 | 25 人 × 280 天的模拟日记录、30 个事件；其中 20 个 Non-contact | 更丰富且独立的球员/赛季，修正后的资格、可用时间、完整随访和明确的恢复定义 |
| 当前动作 | S001–S003、R001；固定人物和侧面镜头；主要支持匀速/减速 | 同一球员同一预测时点的动作、此前个人参考、可控动作变化和非健康原因的行为变化 |
| 配对关系 | 三段动画人为绑定 P001，生成器互不连接 | `episode_id/player_id/season_id/as_of` 贯穿历史、视频、参考和后续事件 |
| 事件时间 | CSV 只有日期 | 若以视频结束为预测时点，需要事件/恢复的模拟时间戳、字段可用时间和明确的未来 168 小时标签 |
| 动作标注 | `annotations.json` 仍为 pending，观察为空 | 独立人工观察、区间和可见性标注；离线制作参数只用于核对 |
| 概率评测 | 现有三段属于开发素材 | 按球员/赛季/事件分组的训练、校准、测试样本及独立动作实例 |

既有 CSV/媒体保留为 v1 演示。新配对数据另建版本；不能给现有随机视频补一个未来标签就称为对齐完成。

## 2. 统一时间与样本合同

建议每条样本为一个观察 episode：

```text
episode_id, player_id, season_id, generator_version
history_cutoff, history_available_at, as_of
current_clip_id, clip_start_at, clip_end_at
reference_clip_id, reference_recorded_at
feature_revision, visual_extractor_revision
followup_end_at, eligibility, exclusion_reason
future_event_id, future_event_at, mechanism, time_loss, label_7d
```

`as_of = clip_end_at`，目标区间为 `(as_of, as_of + 168 小时]`。历史只使用在 as_of 之前可得的信息；首版可继续只使用上一完整日历史，不能把比赛当日全天负荷提前用作输入。参考片段也必须早于 as_of、属于同一球员并有来源。

当前旧演示的“2026-01-24 历史截止 → 2026-01-25 至 01-31”不能直接沿用为看完 01-25 视频后的连续七天窗口。新合同单独冻结时间定义；比赛分钟不是绝对时间戳，需显式映射，不凭比赛分钟简单推算墙钟时间。

新生成器从时间线生成事件时间，不能把原 CSV 的日期擅自补时后声称已恢复原始真值。发生前已有伤病、正在恢复、缺随访均有明确资格规则。首版建议预测未来首次 time-loss 事件为 Non-contact 的累计发生概率：Contact 为竞争事件而非健康标签；Unknown 需按协议处理不确定结果，不能直接认定为确认阴性。若采用不同目标，先修改合同再做标签。

## 3. 合成方法：共同状态生成三类观测

保留 GPT 编写 Blender 脚本、Blender 渲染的路线。新增一个可复现的模拟主控，按以下顺序运行：

1. **球员与历史轨迹。** 生成不同球员基线、赛程、暴露、负荷和恢复轨迹；问卷和心率观测加入测量误差/合理缺失。隐藏状态只存在于离线生成侧。
2. **当前动作状态。** 历史状态加当前短期扰动，形成部分可由视频观察的状态；使视频有机会补充历史未完全记录的信息。另采样战术停步、换节奏等非健康动作原因，避免把减速等同于损伤。
3. **Blender 观测。** 从当前状态生成速度曲线、步频/步幅变化、可控左右节奏差等。先验证现有简化角色能否表达这些变化；不能可靠渲染/识别的维度不进入首版。身体比例、服装、光线、视角、遮挡与结局独立随机化。
4. **未来轨迹与事件。** 当前状态向前随机演化，结合未来模拟活动暴露/恢复生成事件、机制和停训期。当前动作和未来事件共享部分前因，但不从未来标签倒推“必伤动画”。当前动作状态与未来事件的关联强度只是显式模拟参数，不宣称临床依据。
5. **派生可见输入。** 从实际渲染图像提取动作特征，再与历史特征合并。生成器隐变量、内部概率、制作参数、未来暴露/标签均不进入运行时或 LLM 提示。

为避免只学到一条人为规则，预先设置并保留弱关联、无额外视频信号和分布变化的模拟条件。测试新种子/新参数只能检查对这些模拟变化的稳健性，仍不等于真实世界外部验证。

## 4. 必须覆盖的样本与配对控制

- 历史负荷较高但动作稳定；历史看似平稳但当前动作变化。
- 动作明显变化但未来未发生目标事件；动作稳定但未来发生目标事件。随机结果自然保留，不强行改标签凑齐四格。
- 因战术/指令主动减速，和模拟状态相关的动作变化；视觉上难区分时允许不可判断。
- 同一底层 episode 的清楚/遮挡、不同视角/服装版本：共用同一未来结果，不按渲染变体新增伤病事件。
- 个人既往参考与当前片段相匹配，避免拿统一 R001 当作所有球员的正常基线。

刻意平衡的诊断挑战集单独报告，不能作为发生率或校准集。概率评估保留预先定义的目标采样机制和发生率。

## 5. 从视频进入数值模型的最小路径

先复用现有 Foundry VLM，把实际帧转换为少量结构化观察，例如速度变化类别、节奏变化、左右动作差异、相对个人参考变化及可见性。每项带证据帧和不可用原因；VLM 自报 confidence 不是伤病概率，也不视作校准后的测量误差。首轮人工核对能否识别，失败则先修素材/取帧。

比较三个冻结输入路径：训练期发生率基线、历史模型 H、历史＋视频模型 H+V。首版 H/H+V 可用少特征正则化逻辑回归；不训练视频大模型。训练、校准和测试均使用同版实际视觉提取器的输出，不能训练时直接读干净动作参数、上线时换成有误差的 VLM 输出。生成参数可用于独立诊断上限，但要单独标注，不能作为端到端成绩。

不可见动作不是零异常。视频缺失/遮挡时，建议回退到独立评估过的历史模型，并标记“视频未参与”；若无合格历史模型则不可估计。画面差本身不能被解释为生理风险增加。

模型只有在证据包含新信息时才可能改概率，不要求每个视频都改变数值，也不保证变化总是增加风险。判定视频参与要核对结构化特征、模型输入/版本和实际贡献，不能仅看页面数字是否变化。

## 6. 规模、顺序与成本控制

| 阶段 | 建议规模 | 交付/停止条件 |
|---|---|---|
| M0 合同与表格模拟 | 首轮约 200–500 个球员赛季，仅生成轻量表格/时间线 | 输出实际事件数、时间边界与采样分布；规模是起始实验预算，不保证事件率或校准充分 |
| M1 视觉可读性试验 | 约 40 个独立 episode，另加少量相同 episode 的镜头/遮挡变体 | 先低分辨率预览、人工审阅，再小批 VLM；若动作差异不可靠可辨，暂停扩量。此批仅验证配对和视觉链路 |
| M2 联合模型与测量误差试验 | M1 通过后先做约 300–500 个独立 episode | 所有拟使用特征来自实际图像提取；比较 H/H+V、缺视频/错配视频和外观变体，不能将这一规模自动称为概率验证充分 |
| M3 冻结校准/最终测试 | 由目标发生率、独立事件数、区间精度与预设预算反推 | 自然率评估样本事件不足就停止数值发布；不靠增加同事件的帧数或相邻窗口补足事件数 |

例如若目标窗口发生率为 2%，5,000 个独立窗口期望只有约 100 个阳性窗口；这是规模示例，不是本项目已证实发生率、独立事件数或最低样本量。事件聚集、共享球员和重叠随访会降低独立信息量，必须另行计数。

先模拟大量轻量表格、再按预先固定的 episode 抽样规则渲染，避免把全部球员日都制作视频。首轮仍用现有少量帧＋参考帧预算，图像/特征按哈希和提取器版本缓存。批量 VLM 会扩大现有日限额，需先核实单价、预算和批次安排；本计划不自动调高现有 60 次/日模型调用限制，不启动批量付费任务。

如果为节约训练成本抽取更多阳性，保存纳入概率并在训练/评估设计中处理；校准和最终报告不能用未经修正的平衡样本发生率。旧 CSV、旧视频不被覆盖，变体数与独立 episode 数分别报告。

## 7. 验证视频是否提供增量信息

同一球员/赛季、同一事件的重叠窗口、同一底层动作的所有渲染变体均按协议分组；时间向前、清除跨界标签随访。插补/缩放只在训练拟合；视觉提取器和调参只能用开发集，不能看最终测试标签后改提示。原则依据：[scikit-learn 数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)、[分组/时间交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html)。

在同一组冻结测试 episode 上比较 H/H+V 的 Brier、log loss、可靠性曲线及区间/分组波动，辅以 PR-AUC/ROC-AUC；不能以 accuracy 或少量漂亮案例决定发布。校准流程和门槛在测试前冻结，参见 [scikit-learn 概率校准](https://scikit-learn.org/stable/modules/calibration.html)。

补充控制：遮挡不应被当成生理变化；仅换外观不应产生有意义的风险差；缺视频回退路径可用；在合适的历史/活动分层内打乱视频配对后检查增量是否消失，并说明打乱可能制造分布外输入。错玩家/错时间的视频直接拒绝。若 H+V 不优于 H，记录无收益，不加规则强行制造提高。
