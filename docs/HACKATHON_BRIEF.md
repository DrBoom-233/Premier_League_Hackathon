# Hackathon brief

Source: [Microsoft Premier League Hackathon official rules](https://github.com/microsoft/insidethegamehackathon/blob/main/OFFICIAL%20RULES.md) and [official resource playlists](https://github.com/microsoft/insidethegamehackathon/blob/main/RESOURCE%20PLAYLISTS.md). Always check the official pages for the latest details.

## Challenge

Build an AI-powered application or agent that turns synthetic football events into explainable match intelligence, real-time narratives, and automated recaps for studio, broadcast, or streaming use. The experience should be timely, understandable, and adaptable to different fans.

The expected pipeline is:

1. Ingest match events and metadata.
2. Interpret events into football statistics, patterns, and context.
3. Explain why important moments matter.
4. Render insight alongside a match or in a recap.
5. Personalize the experience for different audiences, such as analysts and casual fans.

Possible areas include pass quality, player identification, speed metrics, automatic event detection, narrative generation, tactical/tempo explanations, synthetic data innovation, and multilingual storytelling.

## Eligibility and timing

- Teams may have up to four people.
- Registration period in the published rules ended October 20, 2026 at 12:00 p.m. Pacific Time.
- Submission period ends October 27, 2026 at 11:59 p.m. Pacific Time.
- Judging runs October 27 through November 10, 2026.

## Submission checklist

- New project created after the registration period began.
- Short English project pitch describing what was built, technologies used, and the problem solved.
- Working project and a public demo/testing link with clear instructions.
- Public GitHub repository URL.
- Public demo video under two minutes, hosted on an accepted public platform; show the project running and use only material the team is allowed to publish.
- Make the project freely available to judges for testing through the end of judging.

## Categories

Grand prizes evaluate the overall solution. Category awards include Microsoft Foundry, enterprise readiness, multi-agent systems, and Azure cloud-native integration. Choose a category based on what the finished project actually demonstrates.
